# 明示指定された診断ログだけをファイルへ保存する

## Context and Problem Statement

ACP clientで観測した応答時間とZCode sessionに保存された実行時間が一致しない場合、adapter受信、ACP通知、ZCode hostへの要求、native stdio書き込み、最初のevent受信を区別して計測する必要がある。標準エラーだけではclient processの管理方法によって後から調査できない一方、常時の永続ログやprotocol本文の記録はsecret漏えいと不要な保存を招く。

## Decision Drivers

* PaseoなどのACP clientを変更せずadapter内の待機区間を識別できること
* ACP stdoutへログを混ぜず、既定動作では診断情報を永続化しないこと
* prompt、response、tool入出力、環境値、credential、headerを記録しないこと
* 複数processからの追記でもrecordの順序とprocessを識別できること
* 保存先と保存期間を利用者が明示的に管理できること

## Considered Options

* 明示指定時だけ伏字済み構造化ログをファイルへ複製する
* 常に既定ディレクトリへ診断ログを保存する
* 標準エラーだけを使用し、永続化はACP clientへ委ねる

## Decision Outcome

`ZCODE_ACP_LOG_FILE`に絶対pathが指定された場合だけ、標準エラーと同じ伏字済みJSONL recordをファイルへ追記する。ファイルは`0600`にし、1 recordを1回の同期書き込みで保存する。親directory不在、相対path、open・write失敗は設定エラーとして停止し、別の保存先へfallbackしない。各recordにadapter processの`pid`を含め、正常終了時にdescriptorを閉じる。

公開設定は既存の`ZCODE_ACP_LOG_LEVEL`と`ZCODE_ACP_LOG_FILE`だけとし、自動rotation、既定保存先、CLI optionは追加しない。`debug`ではACP通知とnative stdio書き込みの開始・完了、`info`ではprompt全体の開始・完了要約を記録する。相関情報は`sessionId`、promptごとの`inputId`、内部request ID、method/event type、所要時間に限定し、protocol本文は記録しない。

### Consequences

* Good, because clientとZCodeの間の待機区間を時系列で比較できる。
* Good, because 既定では永続ファイルを作らず、ACP wire形式とstdoutを変更しない。
* Good, because 保存失敗を見逃さず、意図しない別の場所へsecretを含み得る診断情報を残さない。
* Bad, because 同期書き込みの費用が各recordに加わるため、診断が終わったら設定を外す必要がある。
* Bad, because rotationと削除は利用者の責任になり、同じpathを長期間指定するとファイルが増え続ける。

### Confirmation

ファイル未指定時のstderr限定動作、追記順序、`0600`、`pid`、close、無効pathの拒否、stderrとファイル双方の伏字、ACP stdout分離をtestする。遅延する偽ACP通知とnative transportを使い、開始recordが待機前、完了recordが解放後に出ることと、prompt本文がrecordへ入らないことを確認する。

## Pros and Cons of the Options

### 明示指定時だけファイルへ複製

* Good, because 調査時だけ保存を有効にできる。
* Good, because stderrとファイルでredaction policyが分岐しない。
* Bad, because 利用者が絶対pathと削除時期を管理する必要がある。

### 常に既定ディレクトリへ保存

* Good, because 事後調査でログが残っている可能性が高い。
* Bad, because 利用者の明示操作なしに診断情報を永続化する。
* Bad, because platformごとの保存先、rotation、retention policyが追加で必要になる。

### 標準エラーだけを使用

* Good, because adapterの保存責任が増えない。
* Bad, because ACP clientがstderrを保持しない場合に区間計測を後から照合できない。

## More Information
